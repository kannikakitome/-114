
# キャラクター相関図アプリ

ブラウザ上で動く、キャラクター同士の関係性を可視化する相関図ツールです。

## 🌐 実行画面（デモ）
ここに【STEP3で確認したGitHub PagesのURL】を貼り付ける

## ✨ 主な機能
- **スマホ・PC対応**: ドラッグやスライドで画面を自由にスクロールできます。
- **表示の切り替え**: キャラクターのアイコンをタップすると「OPEN / CLOSE」が切り替わり、関係線の表示・非非表示をコントロールできます。
